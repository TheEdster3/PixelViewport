# Changelog

All notable changes to this project will be documented here.

## [Unreleased]

### Added
- Framework-neutral managed/unmanaged frame leases with explicit lifetimes.
- Gray8, Gray16 little-endian, RGB24, BGR24, RGBA32, and BGRA32 pixel support.
- Deterministic pixel inspection and BGRA32 conversion.
- Latest-frame-wins mailbox with drop metrics.
- Avalonia live-frame evaluation adapter and synthetic inspection demo.
- Reproducible CPU conversion probe and expanded CI/package coverage.
- Optional OpenCvSharp adapter with explicit zero-copy ownership and safe-copy paths.
- Headless Avalonia checks for frame presentation, anchored zoom, drag pan, and disposal races.
- Commercial positioning, performance contract, and design-partner playbook.
- Initial `ImageViewport` templated WinUI 3 control.
- Cursor-centered wheel zoom and click-drag panning.
- Fit-to-viewport and actual-size commands.
- Pointer-to-image coordinate reporting.
- Overlay content in image coordinates.
- Pure viewport math library and tests.
- Sample app, package metadata, CI/release workflows, and landing site.
