# PixelViewport documentation

Image display and interaction for .NET vision applications. This documentation describes the public Community alpha, not the planned commercial renderer. Windows is verified; Linux and embedded hardware are unverified.

## Package responsibilities

| Package | Responsibility | Does not provide |
| --- | --- | --- |
| PixelViewport.Core | Image-space geometry and view transforms | UI or buffer ownership |
| PixelViewport.Imaging | Frame leases, pixel formats, conversion, mailbox, rectangle metadata | Camera acquisition or rendering |
| PixelViewport.Avalonia | Raw-frame evaluation viewport | Production GPU pipeline or advanced display transforms |
| PixelViewport.OpenCvSharp | Optional Mat adapter | Native OpenCV runtime or algorithms |
| PixelViewport.WinUI | ImageSource-based zoom/pan and overlay control | Avalonia SubmitFrame API |

The public MIT code can be inspected and redistributed subject to its license and dependency notices. Planned commercial features are not public API. Do not build against names inferred from the roadmap.

## Current capability boundary

Available: six unpacked pixel formats, explicit lifetime leases, bounded/latest-frame-wins submission, CPU conversion, pointer-anchored wheel zoom, drag pan, fit/actual-size, image-space inspection, and basic rectangle outlines in Avalonia. WinUI provides its separate ImageSource and overlay-content model.

Not implemented in the Community alpha: camera drivers, packed Bayer/10/12-bit decoding, float input, window/level, LUT editing, calibrated measurements, editable ROI, GPU/zero-copy presentation, or a WPF adapter. Avalonia rectangle Label/Confidence metadata is accepted but text is not rendered. Browser keyboard controls do not imply equivalent native keyboard shortcuts.

## Version and evidence

API documentation is maintained with the source and compiled examples. Pin the release you evaluate; alpha APIs may change. Download releases from [GitHub](https://github.com/TheEdster3/PixelViewport/releases). NuGet.org listings must be independently confirmed; the current installation path is GitHub packages/local feeds.

The browser illustration is JavaScript, not the native SDK. Published conversion timings exclude acquisition, UI upload, composition, and scan-out. Compare against your own workload and target hardware.

## Documentation maintenance

Source Markdown lives in docs/. The website pages and plain-text AI bundles are generated by scripts/build-docs.mjs. IntegrationExamples.cs is linked into the headless verification project, so its API usage is compiled and exercised in Windows CI. Changes to contracts must update the reference, examples, and tests together.
